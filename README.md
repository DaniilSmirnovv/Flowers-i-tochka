## 🌷 О проекте

**«Цветы - и точка»** - это онлайн-магазин свежих цветов с доставкой. Проект включает в себя:

- 🛍️ **Каталог товаров** с карточками букетов
- 📝 **Оформление заявок** с выбором даты и способа оплаты
- ⭐ **Систему отзывов** после получения заказа
- 🔐 **Авторизацию и регистрацию** пользователей
- 👨‍💼 **Админ-панель** для управления заказами и каталогом
- 🎨 **Современный адаптивный дизайн** с анимациями

## 🗄 Структура БД

База данных: **`flowers`**

### Таблица `users` — Пользователи
| Поле | Тип | Описание |
|------|-----|----------|
| `id` | INT (PK, AI) | ID пользователя |
| `login` | VARCHAR(50) | Логин (уникальный) |
| `password` | VARCHAR(255) | Хеш пароля |
| `full_name` | VARCHAR(100) | ФИО |
| `phone` | VARCHAR(20) | Телефон |
| `email` | VARCHAR(100) | Email |
| `created_at` | TIMESTAMP | Дата регистрации |

### Таблица `products` — Товары
| Поле | Тип | Описание |
|------|-----|----------|
| `id` | INT (PK, AI) | ID товара |
| `name` | VARCHAR(255) | Название |
| `price` | DECIMAL(10,2) | Цена |
| `description` | TEXT | Описание |
| `image` | VARCHAR(255) | Путь к фото |

### Таблица `orders` — Заявки
| Поле | Тип | Описание |
|------|-----|----------|
| `id` | INT (PK, AI) | ID заявки |
| `user_id` | INT (FK) | Ссылка на пользователя |
| `product_name` | VARCHAR(100) | Название товара |
| `delivery_date` | DATE | Дата доставки |
| `payment_method` | ENUM | 'наличные' / 'перевод по номеру телефона' |
| `status` | ENUM | 'Новая' / 'В доставке' / 'Доставлено' |
| `created_at` | TIMESTAMP | Дата создания |

### Таблица `reviews` — Отзывы
| Поле | Тип | Описание |
|------|-----|----------|
| `id` | INT (PK, AI) | ID отзыва |
| `order_id` | INT (FK) | Ссылка на заявку |
| `user_id` | INT (FK) | Ссылка на пользователя |
| `product_name` | VARCHAR(100) | Название товара |
| `rating` | TINYINT(1) | Оценка 1-5 |
| `comment` | TEXT | Текст отзыва |
| `created_at` | TIMESTAMP | Дата отзыва |

### SQL для создания БД

```sql
CREATE DATABASE IF NOT EXISTS `flowers` DEFAULT CHARACTER SET utf8mb4;
USE `flowers`;

CREATE TABLE `users` (
  `id` INT AUTO_INCREMENT PRIMARY KEY,
  `login` VARCHAR(50) NOT NULL UNIQUE,
  `password` VARCHAR(255) NOT NULL,
  `full_name` VARCHAR(100) NOT NULL,
  `phone` VARCHAR(20) NOT NULL,
  `email` VARCHAR(100) NOT NULL UNIQUE,
  `created_at` TIMESTAMP DEFAULT CURRENT_TIMESTAMP
);

CREATE TABLE `products` (
  `id` INT AUTO_INCREMENT PRIMARY KEY,
  `name` VARCHAR(255) NOT NULL,
  `price` DECIMAL(10,2) NOT NULL,
  `description` TEXT,
  `image` VARCHAR(255)
);

CREATE TABLE `orders` (
  `id` INT AUTO_INCREMENT PRIMARY KEY,
  `user_id` INT NOT NULL,
  `product_name` VARCHAR(100) NOT NULL,
  `delivery_date` DATE NOT NULL,
  `payment_method` ENUM('наличные','перевод по номеру телефона') NOT NULL,
  `status` ENUM('Новая','В доставке','Доставлено') DEFAULT 'Новая',
  `created_at` TIMESTAMP DEFAULT CURRENT_TIMESTAMP,
  FOREIGN KEY (`user_id`) REFERENCES `users`(`id`) ON DELETE CASCADE
);

CREATE TABLE `reviews` (
  `id` INT AUTO_INCREMENT PRIMARY KEY,
  `order_id` INT NOT NULL,
  `user_id` INT NOT NULL,
  `product_name` VARCHAR(100) NOT NULL,
  `rating` TINYINT(1) NOT NULL CHECK (rating BETWEEN 1 AND 5),
  `comment` TEXT NOT NULL,
  `created_at` TIMESTAMP DEFAULT CURRENT_TIMESTAMP,
  FOREIGN KEY (`order_id`) REFERENCES `orders`(`id`) ON DELETE CASCADE,
  FOREIGN KEY (`user_id`) REFERENCES `users`(`id`) ON DELETE CASCADE
);
```

## ⚙️ Установка

### Требования
- PHP 8.0 или выше
- MySQL 5.7 или выше
- Веб-сервер Apache/Nginx (или OpenServer/XAMPP)

### Пошаговая инструкция

1. **Склонируйте проект** в корневую папку веб-сервера:
   ```bash
   git clone <repo-url> flowers-shop
   ```

2. **Настройте подключение к БД** в файле `config.php`:
   ```php
   $host = 'localhost';
   $dbname = 'flowers';
   $username = 'root';
   $password = ''; // ваш пароль
   ```

3. **Создайте базу данных** и импортируйте SQL-скрипт из раздела [Структура БД](#-структура-бд).

4. **Создайте папку для загрузок** (если её нет):
   ```bash
   mkdir img
   chmod 755 img
   ```

5. **Откройте сайт** в браузере:
   ```
   http://localhost/flowers-shop/
   ```

## 🛡 Безопасность

- ✅ **PDO с подготовленными запросами** - защита от SQL-инъекций
- ✅ **`password_hash()` / `password_verify()`** - безопасное хранение паролей
- ✅ **`htmlspecialchars()`** - защита от XSS
- ✅ **Валидация на сервере** всех пользовательских данных
- ✅ **Проверка прав доступа** для админ-панели и личных кабинетов
- ✅ **Регенерация ID сессии** при авторизации
